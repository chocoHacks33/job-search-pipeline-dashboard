# Job Search Pipeline Dashboard

A small, dependency-free dashboard for seeing job applications, interview progress, and the next actions that need attention.

## Run locally

Serve the repository with any static file server, then open `index.html`. For example:

```sh
npx serve .
```

## Quality checks

```sh
npm test
npm run check
```

The starter app keeps its example application data in `data.js`, its reusable calculations in `lib/dashboard.js`, and uses no build step or external runtime dependencies.
